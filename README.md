# PIU CheckApp GitHub Pages 사이트

Google Play 등록에 사용할 수 있는 정적 지원 사이트입니다.

## 배포 전 교체

전체 파일에서 아래 문구를 검색하여 실제 값으로 바꾸세요.

- `[Play 스토어 개발자명]`
- `[문의 이메일]`
- `REPLACE_WITH_YOUR_EMAIL@example.com`
- `[YYYY-MM-DD]`

## GitHub Pages 배포

1. GitHub에서 `piu-checkapp-site`라는 Public 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 최상위 경로에 업로드합니다.
3. `Settings → Pages`로 이동합니다.
4. Source를 `Deploy from a branch`로 설정합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
6. 주소 예시:
   - 메인: `https://USERNAME.github.io/piu-checkapp-site/`
   - 개인정보처리방침: `https://USERNAME.github.io/piu-checkapp-site/privacy-policy.html`
   - 계정 삭제: `https://USERNAME.github.io/piu-checkapp-site/account-deletion.html`

이 템플릿은 기술적 시작점이며 법률 자문이 아닙니다. 실제 앱 동작, Firebase 설정, Play Console 데이터 보안 신고 내용과 일치해야 합니다.
