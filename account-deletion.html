PIU CheckApp 계정 및 데이터 삭제

최종 수정일: 2026-08-01

이 페이지에서는 PIU CheckApp의 Google 계정 연결과 관련 데이터 삭제를 요청할 수 있습니다.

앱에서 직접 삭제

  1. PIU CheckApp을 실행합니다.
  2. 계정 → Google 계정으로 이동합니다.
  3. Google 계정 삭제를 선택합니다.
  4. Google 재인증 후 삭제를 확정합니다.

앱 내부 삭제 기능을 사용하면 일반적으로 가장 빠르게 처리가 완료됩니다.

웹에서 삭제 요청

앱을 삭제했거나 앱 내부 기능을 사용할 수 없는 경우 아래 이메일로 삭제를 요청할 수 있습니다.

삭제 요청 이메일 보내기

요청 메일에는 Google 로그인 이메일, 온라인 ID(알고 있는 경우), 계정과 연결 데이터 전체 삭제 요청 문구를 적어 주세요. 계정 소유 확인을 위해 추가 확인을 요청할 수 있습니다. 비밀번호나 Google 인증 코드는 이메일로 보내지 마세요.

삭제되는 데이터

  • Firebase Authentication 계정
  • 공개 온라인 ID와 프로필
  • 친구 관계, 친구 요청, 친구 메모 및 기록 갱신 신호
  • 친구에게 공유된 최고기록
  • Firebase Storage에 저장된 클라우드 백업
  • 계정에 연결된 기기 알림 토큰

기기에 남을 수 있는 데이터

앱 계정 삭제는 서버에 저장된 계정 데이터를 삭제합니다. 사용자의 기기에 저장된 로컬 게임 기록은 별도로 남을 수 있으므로 원하지 않는 경우 앱의 로컬 데이터 삭제 기능을 사용하거나 운영체제 설정에서 앱 데이터를 삭제해 주세요.

처리 기간

앱 내부 삭제는 시스템 상황에 따라 즉시 또는 짧은 시간 내 처리됩니다. 이메일 요청은 본인 확인 후 합리적인 기간 안에 처리하며 완료 결과를 요청 이메일로 안내합니다.
